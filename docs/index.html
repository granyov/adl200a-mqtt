Установка датчиков ADL-200A

Как подключить ячейку давления ACE 1910 к логгеру, перенести её паспорт в настройки, выбрать полосу развёртки и проверить показания до засыпки. Здесь же — масштабы для датчиков с выходом mV, Bridge, Resistance, RTD и Serial.

ПО adl200a-mqtt 1.1.0 · всё на GitHub · подходит и для ячейки 1911

Порядок работы

  1. 1Подключитьпары жил — к струнному входу и термистору одного канала
  2. 2Паспорт в файлкоэффициенты этой ячейки — в sensors.json
  3. 3Настроить каналchannels.py --apply: полоса Sweep 03 и термистор
  4. 4Проверитьживая сессия: статус ok, давление около нуля
  5. 5Смонтироватьснять нулевой отсчёт, записать температуру установки

Шаги 1–4 сначала проходят на столе, до монтажа. После засыпки ошибку подключения или неисправную ячейку уже не исправить.

Команды выполняются на плате, к которой подключён логгер: ssh -t <пользователь>@<плата>. ПО ставится из релиза на GitHub и лежит в /opt/adl200a, настройки датчиков — в /etc/adl200a/sensors.json.

Установка на UVON (Astra 4.7.11 arm64)

scp adl200a-mqtt-1.1.0-offline-astra-4.7.11-arm64.tar.gz <пользователь>@<плата>:
tar -xzf adl200a-mqtt-1.1.0-offline-astra-4.7.11-arm64.tar.gz
cd adl200a-offline-astra-4.7.11-arm64
sudo sh install-offline.sh
sudo adl200a-configure /dev/ttyS5 38400

Первая команда — с ноутбука, остальные — на плате. Установщик сверяет контрольные суммы, архитектуру и версию ОС и в интернет не ходит. В adl200a-configure укажи порт, к которому подключён логгер: /dev/ttyS4 или /dev/ttyS5 на UVON, /dev/ttyUSB0 для Moxa.

Другая плата: только программа

sudo dpkg -i adl200a-mqtt_1.1.0_all.deb
sudo adl200a-configure /dev/ttyS5 38400

Обновление ставится так же, поверх: /etc/default/adl200a и /etc/adl200a/sensors.json сохраняются. Проверить версию: dpkg -s adl200a-mqtt | grep Version.

01

Датчик 1910

Ячейка давления грунта: два стальных диска, сваренных по краю, между ними этиленгликоль. Давление на диск передаётся на струнный преобразователь. Частота струны падает с ростом давления: у ячейки s/n 587968 это 2991 Гц без нагрузки и 2280 Гц на пределе 3,5 кгс/см².

Принципструнный (VW), рядом термистор для температурной поправки
Диапазоны модели2–70 кгс/см², точный — в паспорте ячейки
Разрешение / точность0,025 % / ±0,1 % от верхнего предела (FSR)
Нелинейность±0,5 % FSR
Перегрузкадо 150 % FSR
Уход нуля от температурыменее 0,05 % FSR на °C
Температура работы−40…+80 °C
Термистор3 кОм при 25 °C, ±0,5 °C, −40…+105 °C
Герметичность300 м водяного столба
Размер, масса1910 — Ø230 мм, 4 кг; 1911 — Ø150 мм, 3 кг
КабельØ6,4 мм, 4 жилы по 0,37 мм², экран, оболочка PU

У каждой ячейки свой паспорт калибровки (Calibration Sheet) с коэффициентами по серийному номеру. Чужие коэффициенты брать нельзя, даже от ячейки того же диапазона.

02

Подключение кабеля

Цвета жил — в паспорте, в блоке Cable Connection. Для ячейки 1910:

ПараЖилыКуда на логгере
Frequency — струнакрасная, чёрнаяструнный вход (VW) выбранного канала
Temperature — термисторзелёная, белаявход термистора того же канала
Экран—клемма экрана или земли канала, если она есть
  • Клеммы — по маркировке клеммника ADL-200A.
  • Полярность значения не имеет: катушка струны и термистор не полярные. Важно не перепутать пары между собой.
  • Длина кабеля на струну не влияет — частота не зависит от сопротивления линии. Термистор она занижает, но мало: 25 м кабеля 0,37 мм² — примерно на 0,02 °C, 300 м — примерно на 0,2 °C.
  • Запиши номер канала (1–16) в журнал и промаркируй кабель у клеммника.

Логгер подключается к плате по RS-232, 38 400 бод, 8N1; порт задаёт adl200a-configure при установке. Проверить, что логгер отвечает (подставь свой порт):

sudo systemctl stop adl200a
ADL200A_PORT=/dev/ttyS5 python3 /opt/adl200a/ace.py GTT
sudo systemctl start adl200a

В ответ должно прийти время логгера: <<!01,01,GTT:10:27:16;

    04
    Настройка канала логгера
    
      
    У канала два входа: струнный с полосой развёртки и аналоговый с типом датчика. Логгер возбуждает струну только в выбранной полосе частот. С завода стоит Sweep 01 — 450–1200 Гц, она ячейку 1910 не накрывает: датчик на ней не читается или читается со скачками. Нужна Sweep 03 — 1400–3500 Гц.
    
      
    
      
    Sweep 04 начинается с 2400 Гц и потеряет всё выше ~2,97 кгс/см². "sweep": "auto" выбирает самую узкую полосу, которая целиком накрывает частоты из паспорта, — для 1910 это 03.
    
      
    Сначала сухой прогон — в логгер ничего не пишется:
    
      
    python3 /opt/adl200a/channels.py --apply
    
      
    ≠ 01   VW Sweep 01 (450–1200 Гц) + Thermistor 3K    VW Sweep 03 (1400–3500 Гц) + Thermistor 3K
≠ 02   VW Sweep 01 (450–1200 Гц) + Thermistor 3K    выключен (нет в файле)
  …
  после: включено каналов 1, развёртка ≈ 5 с
  (сухой прогон) >>?1,1,SCC:1,1,1,3,20,6;
    
      
      
        
    • Для ячейки 1910 на канале N уходит SCC:N,1,1,3,20,6.
      • 
        
    • Каналы, которых нет в файле, выключаются. Каждый лишний канал удлиняет опрос примерно на 5 секунд, а при 10–15 включённых логгер начинает тормозить. Если на других каналах есть датчики, которых ещё нет в файле, — сначала внеси их или добавь --keep-others.
      • 
      
    
      
    Если всё верно — записать:
    
      
    python3 /opt/adl200a/channels.py --apply --yes
    
      
    Программа сама остановит службу, снимет копию старой настройки, запишет, перечитает, сверит и вернёт службу. В конце — всё применилось. Посмотреть настройку и откатить:
    
      
    python3 /opt/adl200a/channels.py --show
python3 /opt/adl200a/channels.py --restore /var/lib/adl200a/gcc-backup.txt --yes
    
    
    

    
    
      
    05
    Проверка показаний
    
      
    Живая сессия опрашивает логгер напрямую, новый отсчёт — каждые несколько секунд:
    
      
    ssh -t <пользователь>@<плата> '/opt/adl200a/live.sh -d -z -c 1'
    
      
      
        
    • -d — прямой опрос: служба на время сессии встаёт на паузу и потом возвращается.
      • 
        
    • -z — столбец Δ: изменение от первого отсчёта сессии.
      • 
        
    • -c 1 — только канал 1. -l /tmp/канал01.log — записать сессию в файл.
      • 
        
    • ssh -t обязательно: иначе Ctrl-C не дойдёт до сессии и сводки не будет.
      • 
      
    
      
    по файлу ch01: VW Sweep 03 (1400–3500 Гц) + Thermistor 3K  [полоса выбрана по сертификату]
в приборе ch01: VW Sweep 03 (1400–3500 Гц) + Thermistor 3K

    06
    Монтаж и нулевой отсчёт
    
      
    Монтаж — по проекту и руководству ACE. Из рекомендаций производителя:
    
      
      
        
    • ячейка ставится всей рабочей поверхностью в контакт с грунтом;
      • 
        
    • для точного измерения зазоры между ячейкой, опорной плитой и металлоконструкциями заполняют эпоксидной смолой;
      • 
        
    • в насыпях ячейки обычно ставят группами по 3–5 в разных ориентациях — вертикально, горизонтально, под 45°, как в проекте.
      • 
      
    
      
    Во время засыпки держи открытой живую сессию с -z: столбец Δ показывает, как растёт давление, и сразу видно, не пропал ли сигнал.
    
      
    Нулевой отсчёт. После монтажа, до нагрузки, когда показания установились (температура перестала меняться — обычно через час-два), сними 10–20 отсчётов и запиши в журнал среднее: частоту, digits, давление и температуру. Эту температуру впиши в файл:
    
      
    "initial_temp_c": 12.4
    
      
    От неё считается поправка −Tct·(Tc − Ti). Пока там null, поправка идёт от температуры калибровки. Для 1910 ошибка небольшая — 0,0004 кгс/см² на градус, — но для долгих наблюдений её лучше убрать. Перезапускать ничего не нужно: консольные инструменты читают файл при каждом запуске.

    08
    Что уходит в MQTT
    
      
    Служба публикует сырые значения логгера. Пересчёт в давление в MQTT не подмешивается, чтобы ряд в базе не зависел от файла с коэффициентами, который потом могут поправить.
    
      
    adl200a/ch/01   {"channel": 1, "values": {"t01": 294720, "t06": 3344}, "dev_time": "10:27:59", …}
    
      
      
        
    • t01 — частота струны × 100: 294720 → 2947,20 Гц.
      • 
        
    • t06 — сопротивление термистора, Ом.
      • 
        
    • Как настроен каждый канал и что значит каждый ключ — в retained-топике adl200a/config.
      • 
      
    
      
    Давление из сырых значений — по формуле паспорта, T — температура термистора, Ti — initial_temp_c:
    
      
    Hz = t01 / 100
P  = A·Hz² + B·Hz + C − Tct·(T − Ti)        кгс/см²;  × 98,0665 → кПа
    
    
    

    
    
      
    09
    Другие датчики: mV, Bridge, Resistance, RTD, Serial
    
      
    Кроме струнного входа и термистора у канала ADL-200A есть аналоговые входы. В каком виде логгер передаёт их значения, на живом приборе ещё не проверялось, поэтому масштаб задаёт установщик — в блоке analog_scale записи канала:
    
      
    сырое целое из логгера  × raw_multiplier  →  величина на входе (мВ, Ом, мВ/В …)
величина на входе  →  linear | polynomial | function  →  результат (кПа, мм, °C …)
    
      
    
        
    ПолеЧто это
    
        
          
    sweepnull — у такого датчика нет струнного входа
    
          
    analogmv, bridge, resistance, rtd или serial
    
          
    raw_multiplierво сколько раз умножить сырое целое, чтобы получить величину на входе; подбирается по эталону
    
          
    linearрезультат = gage_factor · (вход − zero_reading)
    
          
    polynomialрезультат = c0 + c1·x + c2·x², списком [c0, c1, c2]
    
          
    functionpt100 или pt1000 — RTD сразу в °C по IEC 60751
    
          
    unit, quantityединица и название результата — для подписи
    
            
      
    
      
      
        
    • Пересчёт — что-то одно из linear, polynomial, function. Без пересчёта показывается только величина на входе — так и подбирается множитель.
      • 
        
    • bridge и serial нельзя ставить на канал вместе со струнным входом — так решил производитель логгера.
      • 
        
    • Коэффициенты пересчёта — из паспорта своего датчика.
      • 
      
    
      
    Как найти множитель
    
      
      
        
    1. Пропиши канал с "raw_multiplier": 1 и без пересчёта, включи: channels.py --apply, затем --yes.
      2. 
        
    2. Подай на вход эталон — калибратор напряжения, точный резистор, имитатор моста.
      3. 
        
    3. Посмотри сырое число в живой сессии live.sh -d -c N: в конце строки mV(t02) 12345 мВ (пересчёт не задан).
      4. 
        
    4. Множитель = эталон / сырое число. Проверь на второй точке у другого края диапазона — помощник ниже сделает это сам.
