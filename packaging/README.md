# Офлайн-установка ADL-200A на UVON / Astra

Готовый полный комплект для **Astra 4.7.11 arm64** опубликован в
[релизе 1.1.0](https://github.com/granyov/adl200a-mqtt/releases/tag/v1.1.0).
Он включает 92 deb: приложение, Python, Mosquitto и всю цепочку зависимостей.
Набор системных зависимостей тот же, что в комплекте 1.0.1, проверенном на UVON
установкой с отключённой сетью; в 1.1.0 заменён только пакет программы.

Подключение датчика и настройка каналов — в
[инструкции установщика](../docs/install-ace-1910.md) и на странице
https://granyov.github.io/adl200a-mqtt/.

```sh
tar -xzf adl200a-mqtt-1.1.0-offline-astra-4.7.11-arm64.tar.gz
cd adl200a-offline-astra-4.7.11-arm64
sudo sh install-offline.sh
sudo adl200a-configure /dev/ttyS5 38400
```

Выбирайте порт по физическому подключению. На тестовом UVON при проверке
обоих встроенных RS-232 не получен ответ логгера; доставка реальных измерений
на этом аппарате требует подключённого ADL-200A. Проверка с временным
MQTT-брокером подтвердила сохранение и доставку тестового ответа после сбоя.

## Что нового в 1.1.0

- Настройка каналов логгера по файлу: `channels.py --apply` записывает полосу
  развёртки Sweep и тип аналогового входа из `/etc/adl200a/sensors.json`.
  Для ячейки ACE 1910 нужна Sweep 03; заводская Sweep 01 её не накрывает.
- Опрос ждёт ровно те типы кадров, что настроены на каждом канале, и не даёт
  развёрткам накладываться; разбор принимает все типы входов (mV, Bridge,
  Serial, Resistance, RTD), а не только VW и термистор.
- В MQTT только сырые отсчёты прибора; расшифровка каналов — в retained-топике
  `adl200a/config`. Блок `eng` и топики `ch/NN/pressure` и т. п. убраны.
- `live.sh` — живая консольная сессия с пересчётом по паспорту; масштабы
  аналоговых входов задаёт установщик (`analog_scale`).

## Доставка

Начиная с 1.0.1 используется тот же механизм доставки, который проверен на Wyse:
MQTT QoS 1, ожидание PUBACK, атомарный файл одного неподтверждённого цикла,
восстановление после перезапуска и остановка нового опроса до доставки.
Это подтверждение приёма брокером. Повторные сообщения возможны, для их
распознавания используется `cycle_id`. Базы данных и архива измерений нет.

## Что входит в deb

`adl200a-mqtt_1.1.0_all.deb` содержит программу, systemd-службу,
pyserial **3.5**, paho-mqtt **2.1.0** и typing_extensions **4.7.1** для Python 3.7,
включая их лицензии. `pip` и сеть при
установке не используются. Архитектура `all`: чистый Python, без нативных
библиотек. Нужны системные Python **3.7+**, systemd и adduser.
Один этот deb НЕ включает Python-интерпретатор или Mosquitto.

Полный комплект — каталог с этим deb, Mosquitto, клиентами, setserial и
всей цепочкой системных зависимостей из репозиториев целевой ОС.
Его нельзя заменять набором deb от другой версии Debian/Astra или архитектуры.
Комплект может обновить установленные зависимости до версий, записанных
в `package-versions.txt`; перед установкой сохраните резервную копию аппарата.

## Установка полного комплекта без интернета

Перенесите и распакуйте весь архив, затем из его каталога:

```sh
sudo sh install-offline.sh
sudo adl200a-configure /dev/ttyS5 38400
sudo journalctl -u adl200a -f
mosquitto_sub -h 127.0.0.1 -t 'adl200a/#' -q 1 -v
```

Установка проверяет SHA256, архитектуру и выпуск ОС. Источники apt отключены,
используется `--no-download`, поэтому недостающий пакет вызывает ошибку,
а не обращение в интернет. Для встроенного RS-232 UVON выбирайте реально
подключённый `/dev/ttyS4` или `/dev/ttyS5`. По последнему отчёту прежний аппарат
работал через `/dev/ttyS5`. Для Moxa используйте `/dev/ttyUSB0`.

Если Python, systemd, adduser и MQTT-брокер уже установлены:

```sh
sudo dpkg -i adl200a-mqtt_1.1.0_all.deb
sudo adl200a-configure /dev/ttyS5 38400
```

Свежая установка включает автозапуск службы; немедленно запускается она
командой настройки порта. При обновлении активная служба перезапускается.
При миграции со старого `install.sh` его unit сохраняется в
`/var/backups/adl200a/`, затем используется unit пакета. Настройки
`/etc/default/adl200a`, `/etc/adl200a/sensors.json` сохраняются при обновлении.
Неподтверждённый `pending.json` сохраняется даже при удалении пакета.
Не запускайте одновременно ручной опрос и службу на одном порту.

## Настройки

Файл: `/etc/default/adl200a`. Свежие значения: ID 1, 38400 бод,
интервал 100 с, ожидание измерения до 90 с, MQTT `127.0.0.1:1883`.
Для внешнего брокера задайте `ADL200A_MQTT_HOST` перед настройкой порта.
Фиктивная калибровка не применяется: свежий sensors.json пустой.
Пакет не меняет включённые каналы и настройки самого логгера.

Moxa требует поддерживаемый драйвер и firmware от целевой ОС. Они не нужны
для встроенного RS-232 UVON и не входят в архитектурно независимый deb.

## Логи на 14 дней

`/etc/systemd/journald.conf.d/zz-adl200a-retention.conf` включает постоянный
журнал в `/var/log/journal`, срок 14 дней, ежедневную ротацию, сжатие и лимит
512 МБ. Это общий системный журнал, включая `adl200a` и `mosquitto`.
При достижении лимита размера или нехватке места старые записи могут удаляться
раньше. Уже удалённые логи не восстанавливаются. Настройка не сохраняет
каждое MQTT-значение: журнал содержит время, состояние циклов, ошибки,
число каналов и подтверждения доставки.

```sh
sudo journalctl -u adl200a --since '14 days ago' --no-pager
sudo journalctl -u mosquitto --since '14 days ago' --no-pager
sudo journalctl --disk-usage
```

## Сборка без сети

На Linux с Python 3.7+ и dpkg-deb:

```sh
python3 packaging/build-deb.py dist
```

Закреплённые wheels уже в репозитории, проверяются их SHA256.
Чтобы подготовить ПОЛНЫЙ комплект, используйте компьютер/VM с интернетом,
**той же версией Astra/Debian и той же архитектурой**, что и целевой UVON:

```sh
sudo sh packaging/build-offline.sh "$(pwd)/dist/adl200a-mqtt_1.1.0_all.deb" "$(pwd)/dist/offline-uvon"
tar -czf dist/offline-uvon.tar.gz -C dist offline-uvon
```

Сборщик только скачивает пакеты; не устанавливает их на сборочный хост.
Зависимости вычисляются с пустой базой установленного ПО, поэтому не
пропускаются пакеты, уже имеющиеся на сборочном компьютере.
