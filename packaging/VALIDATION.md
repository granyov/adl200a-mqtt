# Проверка сборки 1.0.1 — 8 октября 2026

Целевой аппарат: UVON / Forlinx FET3568, Astra Linux **4.7.11 arm64**,
Python **3.7.3**, systemd **241**, Mosquitto **1.5.7** из репозиториев Astra.

- В пакет добавлен typing_extensions 4.7.1: он нужен Paho 2.1.0 для импорта
  Literal на Python 3.7. Проверка на Astra выявила эту зависимость,
  которой не было в сборке 1.0.0.
- Все 12 тестов протокола и очереди прошли на Python 3.7.3: пропавшие кадры,
  паузы, посторонний ID, смешанные времена измерений, неполный GCC, PUBACK,
  запрет перезаписи очереди и сохранение после рестарта.
- С временным брокером Astra проверены отключение MQTT, восстановление ответа
  из файла, PUBACK и фактический приём сообщения подписчиком.
- Полный комплект из **92 deb** (приложение + 91 системный пакет) собран из
  репозиториев Astra 4.7_arm. Пустая база установленного ПО использовалась
  при расчёте всей цепочки зависимостей.
- На UVON выполнена установка через `unshare --net sh install-offline.sh`:
  установщик не имел сети, источники apt отключены, включён `--no-download`.
  На аппарате добавлены 8 пакетов, системные пакеты не обновлялись.
- Повреждённый комплект, неверная архитектура и неверная ОС отвергаются
  до запуска установки.
- `adl200a` запускается как системный пользователь с группой dialout;
  Mosquitto активен, MQTT-соединение устанавливается, native UART открывается.
- journald подтвердил постоянное хранение, 14 дней, ежедневную ротацию
  и лимит 512 МБ; лимит диска может сократить фактический срок хранения.

На этом UVON **не получен физический ответ ADL-200A**: на ttyS5 нет кадров
GCC/MES, отдельный запрос GCC на ttyS4 получил 0 байт. Успех программных
проверок не означает, что логгер подключён и передаёт реальные измерения.

Для базового пакета также проведены проверки в чистом Debian 13 amd64:
установка офлайн-комплекта при отключённой сети, перенос старого systemd-unit,
сохранение порта/калибровок/ожидающего ответа при обновлении. Файл очереди
остаётся даже после purge. Исправление 1.0.1 добавляет библиотеку для Python
3.7 и не меняет эти сценарии миграции.
